# Python vs Other Languages

> Part of [Module 00 — Introduction to Python](../README.md).

Language choice depends on the problem and operating constraints.

| Language | Common strengths | Common contexts |
|---|---|---|
| Python | Developer productivity and ecosystem | Automation, APIs, data |
| C | Low-level control | Embedded and systems |
| C++ | Performance and systems features | Game engines, native software |
| Java | Mature enterprise ecosystem | Enterprise applications |
| JavaScript | Browser and web ecosystem | Frontend and server-side web |

Avoid absolute claims about performance or suitability. Compare actual workloads, libraries, runtime support, deployment constraints and team capability.
