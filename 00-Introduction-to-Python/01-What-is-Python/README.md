# What is Python?

> Part of [Module 00 — Introduction to Python](../README.md).

Python is a high-level, general-purpose programming language. Developers use it to express algorithms, automate work, build services and process data.

## Core terms

- **Programming language:** A formal language for expressing computations.
- **High-level language:** A language that abstracts many hardware and machine-level details.
- **General-purpose:** A language designed for many kinds of software rather than one narrow domain.
- **Runtime:** The environment and services involved in running a program.

## First example

```python
print("Hello, Python Junction!")
```

`print()` writes text to standard output. The string is the argument passed to the function.
