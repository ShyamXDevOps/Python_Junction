# Features and Design Philosophy

> Part of [Module 00 — Introduction to Python](../README.md).

Python emphasizes readable code and a practical balance between expressiveness and simplicity.

## Important features

- High-level and general-purpose.
- Dynamically typed and strongly typed.
- Multi-paradigm.
- Automatic memory management in common implementations.
- Large standard library and package ecosystem.
- Interactive use and scripting support.

## The Zen of Python

The Zen of Python is a collection of design aphorisms. You can display it in an installed Python interpreter:

```python
import this
```

It is guidance and philosophy, not a strict language specification.
