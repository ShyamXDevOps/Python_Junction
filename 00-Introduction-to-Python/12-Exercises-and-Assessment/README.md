# Exercises and Assessment

> Part of [Module 00 — Introduction to Python](../README.md).

# Knowledge check

Answer in your own words before checking official references.

1. Define Python.
2. Who created Python?
3. What does general-purpose mean?
4. Explain high-level language.
5. What does dynamically typed mean?
6. Distinguish Python from CPython.
7. What is bytecode in CPython?
8. What does the Python virtual machine do?
9. What is the standard library?
10. What are pip and PyPI?
11. Give three DevOps tasks that Python can automate.
12. Name two Python trade-offs.

## Practical exercises

### Exercise 1 — First script

Create `hello.py` that prints your own learning goal.

### Exercise 2 — Environment discovery

Run these commands and record their outputs:

```bash
python --version
python -m pip --version
```

If `python` is not the command on your platform, try `python3`.

### Exercise 3 — Explain the workflow

Draw a diagram showing the simplified CPython source-to-execution path.

### Exercise 4 — DevOps use cases

Write five repetitive operational tasks that could be automated with Python. For each, identify the input, action, output and risk.
