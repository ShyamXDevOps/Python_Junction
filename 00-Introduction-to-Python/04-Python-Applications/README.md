# Python Applications

> Part of [Module 00 — Introduction to Python](../README.md).

Python is used across many engineering and research domains.

| Domain | Example |
|---|---|
| Automation | File processing and scheduled tasks |
| Web | REST APIs and backend services |
| Data | Data analysis and ETL |
| AI/ML | Model training and inference workflows |
| Testing | Unit and integration test automation |
| DevOps | CI/CD helpers and infrastructure APIs |
| Security | Log analysis and security-tool integrations |

A language does not automatically make an application secure or scalable. Architecture, libraries, testing, deployment and operational controls matter.
