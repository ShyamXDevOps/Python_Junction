# Advantages and Limitations

> Part of [Module 00 — Introduction to Python](../README.md).

## Advantages

- Readable syntax.
- Broad ecosystem.
- Fast development for many task types.
- Strong support for scripting and automation.
- Extensive learning resources and community.

## Limitations and trade-offs

- Pure Python can be slower than compiled languages for some CPU-bound workloads.
- Dynamic typing makes tests and runtime validation important.
- Dependency and environment management need discipline.
- Threading behaviour depends on the Python implementation and build; conventional CPython builds have a GIL, while free-threaded builds are also available in newer Python releases.

The correct language choice depends on the workload, performance requirements, integration needs, operational environment and team expertise.
