# Python Implementations

> Part of [Module 00 — Introduction to Python](../README.md).

An implementation provides the machinery that runs programs written in the Python language.

| Implementation | Overview |
|---|---|
| CPython | Mainstream implementation, primarily written in C |
| PyPy | Alternative implementation with a JIT compiler |
| Jython | Targets the Java platform; check supported Python version |
| IronPython | Targets the .NET ecosystem; check current compatibility |

For most beginners, start with CPython. Before choosing an alternative, verify its supported Python version, library compatibility, platform support and maintenance status.

References: [Python implementations FAQ](https://docs.python.org/3/faq/general.html#are-there-other-implementations-of-python)
