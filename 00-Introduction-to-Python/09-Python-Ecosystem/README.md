# Python Ecosystem

> Part of [Module 00 — Introduction to Python](../README.md).

The Python ecosystem contains the language, implementations, standard library, third-party packages and packaging tools.

## Key components

- **Standard library:** Modules distributed with Python.
- **Third-party package:** Reusable code distributed separately.
- **pip:** Common package installer.
- **PyPI:** Python Package Index.
- **Virtual environment:** An isolated environment for a project's installed packages.
- **Packaging:** Tools and standards for building and distributing projects.

Do not install packages globally without considering project isolation and dependency management.

References: [Python Packaging User Guide](https://packaging.python.org/) · [PyPI](https://pypi.org/)
