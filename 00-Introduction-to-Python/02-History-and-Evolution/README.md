# History and Evolution of Python

> Part of [Module 00 — Introduction to Python](../README.md).

Python was created by Guido van Rossum and first released publicly in 1991. The language evolved through successive releases, adding capabilities while retaining an emphasis on readability.

## Python 2 and Python 3

Python 2 is end-of-life and should not be selected for new learning projects. Use a currently supported Python 3 release. Compatibility between major generations is not complete, so old Python 2 code may require migration.
