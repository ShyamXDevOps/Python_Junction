# Installing Visual Studio Code

> Part of [Module 01 — Python Environment Setup](../README.md).

Download Visual Studio Code from https://code.visualstudio.com/.

Follow the official installation guide for your operating system and your organization's software policies.

## WSL development

Install the VS Code WSL extension. Open Ubuntu, navigate to a Linux project folder and run:

```bash
code .
```

VS Code should open the folder using its WSL development integration.

Reference: [Developing in WSL](https://code.visualstudio.com/docs/remote/wsl)
