# VS Code Python Extension

> Part of [Module 01 — Python Environment Setup](../README.md).

The Microsoft Python extension adds Python-aware editor functionality such as interpreter selection, IntelliSense, debugging integration and environment workflows.

## Setup

1. Open VS Code Extensions.
2. Search for `Python`.
3. Install the Microsoft Python extension.
4. Open a folder containing Python files.
5. Open Command Palette.
6. Select `Python: Select Interpreter`.
7. Choose the interpreter or `.venv` for the current project.

The extension does not replace the Python interpreter. Select the same environment where the project's dependencies are installed.

Reference: [Python in VS Code](https://code.visualstudio.com/docs/languages/python)
