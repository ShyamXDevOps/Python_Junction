# Python Interpreter and Interactive Shell

> Part of [Module 01 — Python Environment Setup](../README.md).

The interactive interpreter is commonly called the REPL: Read–Eval–Print Loop.

Start it on Ubuntu/WSL:

```bash
python3
```

Example:

```pycon
>>> 10 * 5
50
>>> print("Hello")
Hello
>>> exit()
```

On Windows, use `python` or the Python launcher/manager command appropriate to your installation.

Use the REPL for quick experiments. Use `.py` files for reusable programs, source control and larger work.
